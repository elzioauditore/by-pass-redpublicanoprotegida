🔹 Opción 1: Instalar un Adaptador de Red Virtual (la más limpia)

Windows permite crear adaptadores virtuales que simulan una tarjeta Ethernet.

Método con Administrador de dispositivos:

Presiona Win + X

Abre Administrador de dispositivos

Clic en Acción

Selecciona Agregar hardware heredado

Siguiente → Instalar el hardware manualmente

Elige Adaptadores de red

Fabricante: Microsoft

Selecciona:
👉 Microsoft KM-TEST Loopback Adapter

Eso crea una tarjeta Ethernet virtual que Windows detecta como conectada.

🔹 Opción 2: Usar Hyper-V (si tienes Windows Pro)

Si usas Hyper-V (solo en Windows Pro o superior):

Activa Hyper-V en:

Panel de control → Programas → Activar o desactivar características de Windows

Abre el Administrador de Hyper-V

Crea un Virtual Switch externo o interno

Eso crea un adaptador de red virtual activo.

🔹 Opción 3: Usar software como VMware

Programas como:

VMware Workstation

VirtualBox

Crean automáticamente adaptadores de red virtuales al instalarse.

Aunque no tengas una máquina virtual corriendo, el adaptador aparece como conectado.

🔹 Opción 4: Puente falso (método físico barato)

Existe algo llamado dummy plug RJ45, que es básicamente un conector que engaña al puerto Ethernet haciéndole creer que hay cable conectado.
Cuesta muy poco en línea.


🔹 1️⃣ Ver tus adaptadores de red
Get-NetAdapter

Te mostrará nombre, estado, velocidad, etc.

🔹 2️⃣ Habilitar un adaptador existente

Si ya tienes uno pero está deshabilitado:

Enable-NetAdapter -Name "Ethernet"

Para deshabilitar:

Disable-NetAdapter -Name "Ethernet"
🔹 3️⃣ Crear un adaptador virtual (Loopback)

La forma clásica es instalar el Microsoft KM-TEST Loopback Adapter usando devcon (herramienta de Microsoft).

Primero necesitas devcon.exe (viene en el Windows Driver Kit).

Luego:

devcon install %windir%\inf\netloop.inf *msloop

Eso crea un adaptador Ethernet virtual que aparece como conectado.

🔹 4️⃣ Asignarle IP manual
New-NetIPAddress `
  -InterfaceAlias "Ethernet 2" `
  -IPAddress 192.168.100.10 `
  -PrefixLength 24
🔹 5️⃣ Método más simple (si tienes Windows Pro)

Si usas Hyper-V, puedes crear un switch virtual:

New-VMSwitch -Name "VirtualSwitch" -SwitchType Internal

Eso crea automáticamente un adaptador virtual activo.

🔥 Alternativa rápida (sin WDK)

Si solo quieres que Windows detecte un adaptador activo sin mucho lío:

Instala VirtualBox o VMware Workstation
Ambos crean adaptadores virtuales automáticamente.

🎯 Resumen realista

✔ Crear adaptador virtual → Sí
✔ Habilitar uno existente → Sí
✔ Asignar IP → Sí
❌ Forzar puerto físico a detectar cable → No
